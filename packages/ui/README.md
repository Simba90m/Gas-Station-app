# packages/ui

Reserved for cross-platform UI primitives shared between `apps/admin`
(React DOM) and `apps/mobile` (React Native).

Not built yet — this is Phase 1 (tooling/scaffolding), and there are no
screens in either app yet to share components between. It gets its first
real components in Phase 3 (admin dashboard foundation) and Phase 4
(customer app foundation), built against actual screens rather than
speculatively now.
